Tab Parcel Privacy Policy

Effective date / 発効日: October 12, 2026

English

Tab Parcel is a Chrome extension that saves restorable tabs so the user can restore them later. Users can create parcels manually and can optionally enable a local recovery timeline.

Data handled

When the user explicitly creates a parcel or enables Recovery, Tab Parcel handles tab URLs, titles, order, pinned state, user-entered parcel names, and parcel or recovery snapshot timestamps.

Use, storage, and transmission

This data is used only to display saved parcels and recovery snapshots, and to reopen tabs at the user's request. Recovery is off by default. When enabled, it records changes to restorable tabs in normal Chrome windows and keeps up to 20 recent snapshots. All data is stored locally using chrome.storage.local. It is not transmitted to the developer or any external server. Tab Parcel uses no analytics, advertising, tracking, remote code, or third-party services.

Sharing and sale

Tab Parcel does not share, sell, or allow human access to user data.

Retention and deletion

Data remains on the user's device until the user deletes it or uninstalls the extension. Users can delete individual parcels or clear the complete Recovery history. Uninstalling removes extension storage according to Chrome's behavior.

Permissions

  • tabs: Reads tab metadata, closes tabs after a verified manual save, creates optional local Recovery snapshots, and reopens saved tabs at the user's request.
  • storage: Stores parcels, Recovery settings, and Recovery snapshots locally in the browser.

Tab Parcel requests no host permissions and does not read webpage content.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

Policy changes will be published at this URL with a revised effective date. Questions may be sent to kzmotk+dev@gmail.com.

日本語

Tab Parcelは、復元可能なタブを保存し、あとでユーザーが復元できるようにするChrome拡張です。ユーザーは手動でParcelを作成できるほか、任意でローカルの復元履歴を有効にできます。

取り扱うデータ

ユーザーが明示的にPackを実行した場合、またはRecoveryを有効にした場合に、タブのURL、タイトル、順序、ピン留め状態、ユーザーが入力したParcel名、ParcelまたはRecoveryスナップショットの作成日時を取り扱います。

利用目的・保存・送信

データは保存済みParcelとRecoveryスナップショットの表示、およびユーザー操作によるタブの復元にのみ使用します。Recoveryは初期状態でオフです。有効にすると通常のChromeウィンドウにある復元可能なタブの変更を自動記録し、直近20件まで保持します。すべてのデータはchrome.storage.localを使用して端末内に保存され、開発者または外部サーバーへ送信されません。アクセス解析、広告、トラッキング、リモートコード、第三者サービスは使用しません。

共有と販売

ユーザーデータを第三者と共有または販売せず、人が閲覧できる状態にもなりません。

保持と削除

保存データは、ユーザーが削除するか拡張機能をアンインストールするまで端末内に保持されます。個別のParcelを削除でき、Recovery履歴はまとめて消去できます。アンインストール時にはChromeの仕様に従って拡張機能ストレージも削除されます。

権限

  • tabs: タブ情報の取得、検証済みの手動保存後のタブ削除、任意のローカルRecoveryスナップショット作成、およびユーザー操作による復元に使用します。
  • storage: Parcel、Recovery設定、Recoveryスナップショットをブラウザ内へローカル保存するために使用します。

ホスト権限は要求せず、Webページの本文も読み取りません。

Chrome Web Store Limited Use

Chrome APIから取得した情報の利用は、Limited Use要件を含むChrome Web Store User Data Policyに準拠します。

変更とお問い合わせ

本ポリシーを変更する場合は、発効日を更新して同じURLに掲載します。お問い合わせ先はkzmotk+dev@gmail.comです。
