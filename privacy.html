Tab Parcel Privacy Policy

Effective date / 発効日: October 1, 2026

English

Tab Parcel is a Chrome extension that saves the restorable tabs in the user's current Chrome window so the user can restore them later.

Data handled

Only when the user explicitly creates a parcel, Tab Parcel handles tab URLs, titles, order, pinned state, user-entered parcel names, and parcel creation timestamps.

Use, storage, and transmission

This data is used only to display saved parcels and reopen their tabs at the user's request. All data is stored locally using chrome.storage.local. It is not transmitted to the developer or any external server. Tab Parcel uses no analytics, advertising, tracking, remote code, or third-party services.

Sharing and sale

Tab Parcel does not share, sell, or allow human access to user data.

Retention and deletion

Data remains on the user's device until the user deletes an individual parcel or uninstalls the extension. Uninstalling removes extension storage according to Chrome's behavior.

Permissions

  • tabs: Reads tab metadata in the current window, closes tabs after a verified save, and reopens saved tabs at the user's request.
  • storage: Stores parcels locally in the browser.

Tab Parcel requests no host permissions and does not read webpage content.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

Policy changes will be published at this URL with a revised effective date. Questions may be sent to kzmotk+dev@gmail.com.

日本語

Tab Parcelは、現在のChromeウィンドウにある復元可能なタブを保存し、あとでユーザーが復元できるようにするChrome拡張です。

取り扱うデータ

ユーザーが明示的にPackを実行した場合に限り、タブのURL、タイトル、順序、ピン留め状態、ユーザーが入力したParcel名、Parcelの作成日時を取り扱います。

利用目的・保存・送信

データは保存済みParcelの表示と、ユーザー操作によるタブの復元にのみ使用します。すべてのデータはchrome.storage.localを使用して端末内に保存され、開発者または外部サーバーへ送信されません。アクセス解析、広告、トラッキング、リモートコード、第三者サービスは使用しません。

共有と販売

ユーザーデータを第三者と共有または販売せず、人が閲覧できる状態にもなりません。

保持と削除

保存データは、ユーザーが個別のParcelを削除するか拡張機能をアンインストールするまで端末内に保持されます。アンインストール時にはChromeの仕様に従って拡張機能ストレージも削除されます。

権限

  • tabs: 現在のウィンドウのタブ情報取得、保存検証後のタブ削除、およびユーザー操作による復元に使用します。
  • storage: Parcelをブラウザ内へローカル保存するために使用します。

ホスト権限は要求せず、Webページの本文も読み取りません。

Chrome Web Store Limited Use

Chrome APIから取得した情報の利用は、Limited Use要件を含むChrome Web Store User Data Policyに準拠します。

変更とお問い合わせ

本ポリシーを変更する場合は、発効日を更新して同じURLに掲載します。お問い合わせ先はkzmotk+dev@gmail.comです。
